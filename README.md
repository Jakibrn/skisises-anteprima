# Anteprima di design: Ski Sises

Prototipo statico del nuovo aspetto di skisises.com, per raccogliere commenti: https://jakibrn.github.io/skisises-anteprima/

Non è il negozio: non vende nulla e i moduli non inviano dati. Per acquistare: https://skisises.com

Su ogni pagina, «Commenta» lascia una nota in un punto preciso; alla fine «Manda su WhatsApp» o
«Manda per email» spedisce tutte le note insieme. Le pagine hanno `noindex`.
